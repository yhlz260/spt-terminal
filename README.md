# 三重仓职业终端 · 融合版

A 股「5/3/2」仓位体系（5 成埋伏 / 3 成波段 / 2 成短线）的单文件行情终端，共 17 个功能页。

## 在线使用

**https://yhlz260.github.io/spt-terminal/**

手机、平板、电脑浏览器直接打开，无需安装、无需构建。

## 功能页

| 分组 | 页面 |
|---|---|
| 决策 | 总览 · 信号捕捉 · 三重仓决策 · 波段监控 · 今日推荐 |
| 资金 | 主力资金 · 复盘中心 · 模拟仓对比 |
| 风控 | 全市场雷达 · 市场 Regime · 风险排雷 P0 · 组合风控 P2 |
| 审计 | 因子/审计 · 纪律审计 · 推荐跟踪 |
| 研究 | 信号回测（含净值/基准、成本与涨跌停约束、显著性检验、Walk-forward、Bootstrap、成本×持有期敏感性）|

## 技术要点

- **单文件 HTML**，零构建、零依赖安装；图表优先内联 SVG，规避外部 CDN 不可达。
- **数据策略**：实时行情优先 + 快照兜底，界面角标明示当前数据来源与构建版本。
- **配色遵循 A 股习惯**：红涨绿跌。
- **仓位口径唯一**：全局 `POSITION_POLICY`（埋伏 50 / 波段 30 / 短线 20；单票上限 15%、短线 5%、止损 5%）。
